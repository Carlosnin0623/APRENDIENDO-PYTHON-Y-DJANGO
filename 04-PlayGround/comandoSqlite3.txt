################# Instalar sqlite3 #####################
1- Descargar sqlite3 en windows.
2- Descomprimir los archivos de la carpeta descargada
3- Crear una carpeta llamada sqlite3 en el disco C: y meter los archivos ahi dentro.
4- Entrar a "Editar variables de entorno del sistema" y en el path agregar el archivo sqlite3.exe
5- Ya con esto tendremos funcionando sqlite3 en windows.

/* Comandos para migraciones a sqlite3 dentro de un proyecto de Django */

1- Entrar al proyecto
2- Ejecutar las migraciones: usa este comando python manage.py migrate, este comando nos creará las tablas por defecto
y configuraciones iniciales del proyecto, como por ejemplo el panel de administracion de Django.

3- Los modelos deben ser creados dentro de la carpeta model de cada aplicacion en este
caso estaremos usando la carpeta model de la aplicacion minilibrary:

from django.db import models

# Create your models here.
class Author(models.Model):
    name = models.CharField(max_length=100)
    birth_date = models.DateField(null= True, blank=True)


class Book(models.Model):
    title = models.CharField(max_length=200)
    publication_date = models.DateField(null=True, blank=True)
    author = models.ForeignKey(Author, on_delete= models.CASCADE, related_name="books")
    pages = models.IntegerField()
    isbn = models.CharField(max_length=50)

Debes ejecutar el siguiente comando ->  python manage.py makemigrations minilibrary -- poner siempre el nombre de la aplicacion
-- Esto nos dara un preview de como se crearian los campos y relaciones en la base de datos
antes de crearla.


Luego tenemos el siguiete comando -> python manage.py showmigrations, esto es para ver cuales aplicaciones
faltan por realizar las migracione y cual todavia no tienen migraciones. las que tiene X son las que
